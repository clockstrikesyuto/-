# ROUTE RUSH

2人で同じ迷路を同時に指でなぞり、先にゴールした方がラウンドを取るリアルタイム対戦ミニゲーム。

- 2人専用オンライン対戦
- 4桁ルームコード + QR参加
- 3本勝負 / 5本勝負
- 同じシードから同一迷路を生成
- 相手の盤面は見えず、進捗バーだけ表示
- 壁に触れると `BUMP!` + 約0.7秒停止 + チェックポイントへ戻る
- ラウンドは自動進行、最後にスコア表示
- ホストからそのまま再戦可能

## Local

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open http://127.0.0.1:8000
